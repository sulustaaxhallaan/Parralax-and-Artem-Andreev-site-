# Портфолио — Артём Андреев

Сайт-портфолио графического дизайнера. Контент перенесён из «Черновик Сайта.pdf».

```bash
npm run dev
```

## Как всё устроено

Сайт — **один неподвижный кадр с общим фоном**. Секции не листаются
по отдельности: они проявляются и гаснут поверх одного и того же фона,
а «плеером» служит обычная прокрутка страницы.

Исключение — лента кейсов: она живёт своей жизнью. Колесо над ней
крутит годы по горизонтали, ленту можно тащить мышью или листать
пальцем. Доехав до края, лента отдаёт колесо странице — иначе на
секции можно было бы застрять.

| Файл | Отвечает за |
| --- | --- |
| `src/content/site.ts` | **весь текст, ссылки и кейсы** — правь здесь |
| `src/lib/stage.ts` | таймлайн прокрутки: порядок секций и запас времени |
| `src/lib/useStageScroll.ts` | перевод прокрутки в «экраны» и сглаживание |
| `src/app/components/Stage.tsx` | сборка сцены |
| `src/app/components/Background.tsx` | фон: свечения за курсором, дуги, зерно |
| `src/app/components/SectionLayer.tsx` | появление/исчезновение одной секции |
| `src/app/components/FitToViewport.tsx` | вписывает секцию в высоту экрана |
| `src/app/components/motion/` | анимации текста: набор, пословное появление |
| `src/app/components/sections/` | сами секции |
| `public/cases/` | картинки кейсов, нарезанные из черновика |
| `public/hero/turn/` | 72 кадра поворота модели на первом экране |
| `scripts/hero-frames.py` | скрипт, который режет эти кадры из видео |

## Частые правки

**Поменять текст.** Всё в `src/content/site.ts`. Компоненты трогать не нужно.

**Секция мелькает слишком быстро.** В `src/lib/stage.ts` увеличь `hold`
у нужной секции. Единица — один экран: `hold: 1.5` значит «полторы
высоты окна прокрутки, пока секция полностью видна». `FADE` там же
задаёт длину кросс-фейда между секциями.

**Сделать кейс кликабельным.** Добавь `href` в нужный элемент
`cases.years[].items[]` — карточка сама станет ссылкой.

**Контакты и соцсети.** `contacts.items` и `contacts.socials`
в `site.ts`. Для WhatsApp и Telegram там стоят пометки `TODO` — впиши
свои адреса.

**Форма обратной связи.** Пока `feedback.endpoint` пустой, форма
открывает почтовый клиент с готовым письмом на `feedback.mailTo` —
сайт работает без бэкенда. Впишешь URL обработчика (Formspree,
Getform или свой `/api/contact`) — форма начнёт слать туда POST
с JSON `{ name, contact, message }`.

**Заменить картинку кейса.** Положи файл в `public/cases/`, укажи путь
в `site.ts` и поправь там же `w` и `h` — они нужны, чтобы вёрстка не
прыгала при загрузке. Картинки в репозитории нарезаны из PDF; если есть
исходники в большем разрешении — лучше подменить их.

## Модель на первом экране

В `public/hero/turn/` лежат 180 кадров поворота на 360° с шагом 2°,
нарезанные из видео. Крутит их `HeroModel.tsx` на `canvas`: фигуру можно
тащить мышью или пальцем, после броска она докручивается по инерции,
а в покое медленно поворачивается сама — примерно оборот за сорок секунд.

Все 180 кадров в память не помещаются, поэтому каждый двенадцатый висит
там постоянно, а остальные подгружаются по ходу вращения и вытесняются
самыми старыми. Пока секция не на экране, цикл отрисовки не работает —
иначе телефон грелся бы всю прокрутку.

Фон из кадров не вырезан, и граница сделана намеренной — светящаяся
рамка `FRAME_GLOW`. До неё стык пытались растворить мягкой кромкой и
подложкой в тон, но это не работает: растушёвка размазывает переход,
а разницу в середине пятна убрать не может. На тёмных участках фона
стыка не было видно, на светлых кадр читался панелью. Рамка снимает
вопрос целиком — она одинаково уместна на любом фоне.

Фигура стоит в общем потоке рядом с текстом, а не поверх него. С `lg`
она справа от заголовка и выровнена по центру экрана, ниже — над
текстом. Низкие окна (телефон боком) тоже уходят в строку: колонкой
фигура и текст туда не помещаются. Вертикальный свайп всегда листает
страницу, вбок — крутит модель.

**Если меняешь видео.** Впиши путь в `SRC` внутри скрипта и запусти:

```bash
python scripts/hero-frames.py
```

Нужны `opencv-python`, `pillow` и `numpy`. Требования к исходнику:
неподвижная камера и полный оборот.

Две тонкости, ради которых скрипт вообще нужен:

*Скорость вращения в исходнике неравномерна.* В текущем видео разброс
больше чем в десять раз: местами фигура почти стоит, местами летит.
Поэтому кадры берутся равномерно не по времени, а по накопленному
изменению картинки — то есть примерно по углу. Иначе лента дёргается
при перетаскивании.

*Кадров в обороте конечное число.* Здесь их 292, и после выравнивания
по углу 180 — предел, на котором кадры ещё почти все различны: при 240
дублей уже 13%, при 360 — 30%, то есть треть файлов весит впустую.
Больше можно взять только с более длинного видео на ровной скорости.

Обрезка `CROP` подобрана по кадрам вручную: чем меньше в кадре пустого
фона, тем меньше он выдаёт себя панелью на светлых участках страницы.
**Меняешь видео — проверь рамку заново**, автоподбор здесь ненадёжен.

**Важно после замены картинок:** удали `.next/dev/cache/images` —
иначе браузер продолжит показывать старые версии, даже после
перезапуска сервера.

## Доступность

Все анимации выключаются при системной настройке «уменьшить движение»:
текст показывается сразу, фон перестаёт следовать за курсором.
